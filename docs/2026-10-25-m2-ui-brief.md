## 1. Rules

- Kotlin + Jetpack Compose (BOM 2026.09.00: foundation, material3 only where a widget saves real work, e.g. nothing is
  required from it). **No new dependencies.** No navigation library: `app/` owns navigation (`MainActivity.kt`).
- **Tokens only in `core/designsystem/.../LectriceTheme.kt`.** No `Color(0x…)` anywhere else (a test will grep). Sets: light,
  dark (`bg #121417` …), black (true black, design brief §9.1 "Option 3 dark" values + the rest from dark). `ThemeSetting.System`
  follows the phone and uses **dark** (not black). Expose them as an immutable `LectriceColors` through a
  `CompositionLocal` (`LectriceTheme.colors`), with type styles (`LectriceTheme.type`) per design brief §9.3 (Quiet rows
  16/20 500, meta 14/18), reading text `FontFamily.Serif` (Noto Serif on Android), code `FontFamily.Monospace`. Add the cover
  hues (6 pairs, light and dark) to the tokens.
- Components are **stateless** (parameters in, lambdas out). Screen-local view state (`rememberSaveable`): sheet open,
  follow-scroll, Listen view open, search text. Business state comes only from the UiState.
- **No visible scrollbars** anywhere (Compose draws none by default; don't add any). Code blocks scroll sideways with the 24 dp
  right-edge fade only while more is hidden (README §4.4).
- Copy: static texts in each module's `src/main/res/values/strings.xml`; dynamic labels already come formatted in the state
  (e.g. `ContinueCard.timeLeft`, `PlayerInfo.location`).
- Accessibility (README §4.5): 48 dp targets, content descriptions from the copy tables, TalkBack custom actions for every
  gesture, reduced motion (`Settings.Global.ANIMATOR_DURATION_SCALE == 0` → instant), font scale to 200 % (R12, R12b).
- Springs: `spring(dampingRatio = 0.85f, stiffness = Spring.StiffnessMediumLow)`. Sheets follow the finger
  (`AnchoredDraggable`), detents per file 05 §3.6. Edge-to-edge: pad with `WindowInsets` (status, navigation bars).
- Never log book text. No `println`.
- Minimal comments (only non-obvious intent). Self-review your diff; remove unused code.

## 2. What to build

### Part A (one agent): design system, Library, Settings

**`core/designsystem`** (package `app.lectrice.core.designsystem`):
- `LectriceTheme(theme: ThemeSetting, content: @Composable () -> Unit)` — also sets the status/navigation bar icon colours
  for light/dark.
- `Icons.kt`: `ImageVector`s for every icon used (port the SVG paths from the mockup's `ICONS` table; Material Symbols
  outlined, 24 dp viewport).
- Components (names are suggestions; keep them small): `PrimaryButton`, `SecondaryButton`, `LectriceTextButton`,
  `LectriceIconButton`, `ListRow` (Quiet density), `LectriceSwitch`, `SegmentedControl` (the `.segc`), `ChoiceChip`,
  `LinearProgress` (4 and 8 dp, determinate/indeterminate), `Spinner` (16 dp), `Banner` (warn/err/ok variants),
  `LectriceSnackbar` (inverse colours, optional underlined action), `BottomSheet` (modal, scrim, handle, half/full detents,
  drag + fling, `onDismiss`), `LectriceDialog`, `CoverTile` (initials + hue), `SectionHeader`, `ProgressBarSmall` (56×4).
- A contrast unit test (`core/designsystem/src/test`) that computes WCAG contrast for every text/background pair listed in
  design brief §9.2 for light, dark and black and fails below 4.5 (plain JVM: keep the colour values in a form the test can
  read without Android, e.g. `Long` ARGB constants in the token file).
- App launcher icon in `app/src/main/res`: adaptive icon, background `#1D5FAE`, foreground the white Material Symbols
  `menu_book` glyph centred at 50 % of the 108 dp canvas; monochrome layer = the same glyph. Then add
  `android:icon="@mipmap/ic_launcher"` back to `app/src/main/AndroidManifest.xml`.

**`feature/library`**: `LibraryScreen(state: LibraryUiState, actions: LibraryActions, onPickPdf: () -> Unit)`
(file 02, 03 §3.6, 21): L1 (Quiet header + settings button, Continue card with the 3 dp accent bar, "Recent" rows with
cover tiles and "Continue · 34 %"/"Start", FAB `note_add` bottom-right), L2 empty, L3 import rows (running: indeterminate bar
"Reading… cleaning text"; queued: "Waiting…"), L4 import error sheet (copy per error name in file 03 §3.6, curly quotes,
sizes via `app.lectrice.core.model.Sizes`), L5 banner (+ the downloading and engine-failed banners of file 02 §3.6), loading
(nothing for 150 ms, then 3 placeholder rows), list error banner with "Try again", L6 snackbar, L7 book sheet (long-press a
row or the card; TalkBack custom action "Remove from library"), L7c confirm dialog (file 21 §3.1; checkbox only when
`exportCount > 0`), L7u snackbar with Undo (8 s), R12b (200 %: card stacks its button). Paging: call `actions.loadMore()`
when 5 rows from the end. Continue card: tap body → `openBook(id, false)`, play button → `togglePlayOnCard()`.

**`feature/settings`**: `SettingsScreen(state: SettingsUiState, actions: SettingsActions, onBack: () -> Unit)` (file 11 §3.1,
T1 and the T1 rows of the v2 brief §4): sections Listening / Reading / Voice model / Storage / Battery / About, the text-size
5-stop slider with the live preview line, theme segments System · Light · Dark · Black, the default-voice sheet (grouped
voice list with a 48 dp sample button per row → `playVoiceSample`), default-speed sheet (6 segments), read-ahead sheet
(three radio rows). Long-press the version row → `copyVersion()`.

**Also in `feature/settings` (M4 screens; designs: the mockup's S1–S4, T2/T2b/T2c, T3 group and the new-screens set
`../lectrice/docs/progress/android-new-screens.md` + `design/screens/android-q2-T3*.png`):**
- `WelcomeScreen(onGetVoice, onNotNow)` (S1), `ChooseModelScreen(state: ModelSetupUiState, actions: ModelSetupActions,
  onImportFile: () -> Unit, onBack)` (S2/S2s/S2b dialog; **three cards** now — Fast (Recommended), Full quality, Small —
  using each `ModelCard`'s name, description, sizeLine, speedNote; "Not sure? Pick Fast." replaces "Not sure? Pick Full
  quality."), `DownloadScreen(state, actions, onOpenPdf, onLibrary)` (S3, S3a–S3d, S4 with the sample card; S4 shows the
  slow-phone line "This phone makes speech slower than real time. Prepare books while charging for smooth listening." when
  `state.slowPhone`), `ModelPageScreen(state, actions, onBack)` (T2: one card per model with Use this / Delete / Download /
  progress; T2c dialog from `SetupDialog.Delete`).
- `StorageScreen(state: StorageUiState, actions: StorageActions, onBack, closeInsteadOfBack: Boolean)` (file 20 §3.5:
  summary card with the 5-segment bar using the cover hues, sections Voice models / Books / Audio cache / Exported
  audiobooks / Phone, dialogs T3d "Delete all Lectrice data" and the export delete confirm).
- `LicensesScreen(onBack)`: `Licenses.GPL_NOTICE` first, then `Licenses.components` rows; tapping a row shows its texts
  (read from `assets/licenses/<file>`).

### Part B (a second agent, after Part A): Reader, pill, player sheet, chapters, Listen view, export page

**`feature/reader`**: `ReaderScreen(state: ReaderUiState, actions: ReaderActions, onBack: () -> Unit,
onListenViewChanged: (open: Boolean) -> Unit)`:
- Reader text (file 04): `LazyColumn`, one item per `ReaderBlock`, key = block id; paragraphs as one `Text` with an
  `AnnotatedString` (current sentence: `hl`/`hlFg` background with radius 4, 120 ms cross-fade); page chips inline
  (`InlineTextContent`); headings 1–3 sizes; code/table boxes scroll sideways with the fade and the cue line; captions italic;
  list items with a bullet. Text sizes scale with `state.textSize.scale` (paragraph sp = `textSize.paragraphSp`, line
  height × 1.68). Tap → the sentence under the finger → `jumpToSentence(id)`; tap on a code/table/caption block →
  `tapBlock(index)`. Status scrim. Follow-scroll (35 % target, 20–60 % band; a user drag turns it off; `state.followRequest`
  changes turn it on), "Back to current" chip (R2) with ↓/↑.
- States: `ReaderContent.Loading` (spinner after 150 ms), `Recleaning` ("Updating this book's text…" + indeterminate bar),
  `Failed` (err text + "Try again" → `onBack`), banners R9 (`ReaderBanner.VoiceFailed`) and R7 (`SlowPhone`, "Set 1.25×"),
  snackbar for `ReaderMessage.SentenceSkipped` ("Couldn't read one sentence, so it was skipped.").
- The pill (file 05 §3.1–3.5, 3.7): expanded (⏮ ⏯ ⏭, status with `open_in_full`, ⋯), collapsed (round button + 2 dp book
  progress line), collapse/expand rules, the gesture map (README §4.1: tap vs drag vs swipe thresholds), the speed scrubber
  on long-press of ⏯, the one-time hint R1h (`pillHintSeen` / `pillHintDone()`), status text widths (speed part only ≥ 400 dp,
  sleep part, below 360 dp only the icon), `voiceMissing` → "Voice not installed / Tap to download" → `openModelSetup()`,
  status `VoiceFailed` → shows R9. Status text = `player.location` parts joined by " · " (only `shrinks` parts ellipsize).
- Player sheet R4/R4x (file 05 §3.6): transport with section buttons, book slider (thumb, buffered part, chapter ticks,
  bubble from `seekLabel`, release → `seekTo`), chapter line (opens chapters), Speed segments, Voice row expanding inline
  (current voice first, its group, "All 28 voices"), Sleep timer row with chips Off/15/30/45/60/End of chapter
  (`SleepTimer.Minutes(total, total*60_000)`, End of chapter disabled without a TOC), "Read code & tables aloud" switch,
  "Export audiobook" row → `openExport()`, "Library" row → `openLibrary()`.
- Chapters sheet (file 07 §3.4): full height, search field (`searchOutline(query)` returns the rows to show, with match
  ranges to bold), sticky level-1 headers, current-path accent bars, centred on open, tap → `jumpToSentence(row.sentenceId)`
  and close; R8c empty text when `outline` is empty.
- Listen view (file 06, v2 brief §5.3, R13 group): opened by tapping the pill status (container transform from the pill),
  top bar with chevron + titles (drag down to close), teleprompter (previous / current with the 3 dp accent bar / next),
  thumb zone (chapter progress with section ticks, transport 64/88/64, Section buttons, tool row Speed · Sleep · Chapters ·
  More), tap = play/pause with a 600 ms icon flash, swipe = next/previous, code card R13c, hint R13h (`listenHintSeen`),
  predictive back (shrink towards the pill). Call `onListenViewChanged(true/false)` when it opens/closes (the app keeps it
  over the lock screen when that setting is on).
- Export page (file 10, v2 brief §5.4, new-screens E5–E7): `ExportPage(state: ExportUiState, actions: ExportActions,
  onBack, onSaveAs: () -> Unit)` pushed inside the player sheet. **No Format group (M4B only)**; Quality lists the three
  models (`QualityRow`, with "Download · 140 MB"); the footer from `ExportFooter` (E6 card when `fits == false`, with
  "Export part of the book" when `canExportPart`); E7 page (`ExportPage.Part`: From/To rows opening a chapter list of
  `rangeChoices`); progress pages per `ProgressKind` (copy in file 10 §3.1); E4 done with Save to Audiobooks / Save as… /
  Share / Make another version; the cancel dialog. `ReaderScreen` gets an extra parameter `exportPage: @Composable
  (onBack: () -> Unit) -> Unit` that the app fills (the export ViewModel is created by the app); the player sheet's
  "Export audiobook" row pushes it.

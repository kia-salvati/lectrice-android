# M2 · Foundation, library, reader, chapters (2026-10-25/26, Opus + Fable)

Plan: `docs/2026-10-25-m2-build-plan.md`. Branch `feature/app-m2` (local, nothing committed). M2–M4 were built in one
pass because the user asked for every milestone; this file covers the M2 parts, `M3.md` and `M4.md` the rest.

## What was built

**Gradle modules** (all Android libraries except `app`; shared settings in the root `build.gradle.kts`):
`core:model`, `core:data`, `core:playback`, `core:work`, `core:designsystem`, `feature:library`, `feature:reader`,
`feature:settings`, `app`. `spike` stays as it was (only kept compiling against the new FFI).

**`core:model`** (pure Kotlin): `Document`/`Block`/`Sentence`/`TocEntry`, `ErrorName` (mirror of the Rust registry) +
`LectriceError`, `Toc` (port of the web's `toc.ts`, section jumps, outline search with accent folding), `Pages`
(`planPageMarkers`, `printedLabel`), `PlaybackOrder` (lookups over the core's `playback_order`), `Progress` (percent,
time left, relative time), `PlaceLabels` (pill / card / sheet / Listen view / media labels, file 07 §3.3), `Covers`,
`Sizes`, `PlaybackController` + `PlaybackState`, `SettingsStore` + `AppSettings`, repositories, `ImportQueue` (one
import at a time), `RemovalController` (soft remove, 8 s undo, purge), `PositionSaver` (5 s trailing debounce),
`ExportSpace` (file 10 §3.11), and the export / prepare / model interfaces used by M3–M4.

**`core:data`**: `RustCore` (owns the uniffi core; every call on IO; main-thread calls throw in debug), `Mappers`,
`CoreLibraryRepository` (SAF copy with the size and space checks of file 03, import, documents, remove/restore/purge,
storage usage), `PreferencesSettingsStore` (one `SharedPreferences` file instead of DataStore, see plan §5),
`CoreVoiceRepository`, `ModelCatalog` / `ModelStore` / `EngineFactory` / `EngineHost` / `DeviceProfile` (M3/M4),
`ModelInstaller`, `CoreExportRepository` (M4). The Gradle task `buildRustFfi` runs `rust/build-android.sh sherpa1` and
generates the uniffi bindings into the module.

**`lectrice-ffi`** (Rust, Android repo): `list_recent`, `document_summary`, `save_position`, `current_cleaner_version`,
`remove_document`, `restore_document`, `purge_removed`, `clear_document_audio`, `storage_usage`, `clear_audio_cache`,
`error_registry`, `core_version`; `list_voices` falls back to the Kokoro catalog without an engine. Test
`tests/error_registry.rs` keeps Kotlin's `ErrorName` equal to the Rust registry (it parses `ErrorName.kt`).

**ViewModels and state contracts** (Opus): `LibraryViewModel` (paging 20, Continue card filled from the card's document,
import outcomes, book sheet, remove/undo), `ReaderViewModel` (open + re-clean detection, reader blocks off the main
thread, place labels, player info, Listen view info, chapters outline + search, section jumps, slider, slow-phone tip,
prepare), `SettingsViewModel`. The UI (Compose) is Fable's (see `M2-ui-A.md`, `M2-ui-B.md`).

**App**: `MainActivity` (one Activity, our own `Navigator` back stack with slide transitions, intents "Open with" /
"Share", first run → S1, notification permission asked once before the first play or download), `AppContainer`
(hand-written DI), `LectriceApplication`, manifest, backup rules (settings only), `ManageSpaceActivity` (M4).

## Core change (main repo, worktree `../lectrice-core-android`, branch `feature/core-android`, uncommitted)

- `KokoroSpeechEngine::voice_catalog()` (voices without loading a model).
- C21 prepare jobs and `AudioRetention::pin`/`unpin` (M4, see `M4.md`).
- CHANGELOG `[Unreleased]` lists them. The worktree is used through the gitignored `.cargo/config.toml` path override.
  Our Fast/Small engine ids need **no** core change: `lectrice-ffi` wraps them in `BundleSpeechEngine`
  (same ids as the desktop: `kokoro-v1.0-lectrice-fast-v1`, `kokoro-v1.0-lectrice-small-v1`, `kokoro-v1.0`).

## Pin

`rust/lectrice-ffi/Cargo.toml`: `tag = "v0.3.0"` (was `v0.2.0`). The new core API above needs the next core release; until
then builds use the path override.

## Dependencies added (verified)

Gradle's `--write-verification-metadata pgp,sha256 --export-keys` (signed artifacts by key; unsigned AndroidX module/POM
files pinned by SHA-256 from the mirror, as before). By hand: junit 4.13.2 (Marc Philipp key, already trusted) and
hamcrest 1.3 (key `4DB1A497…893E` from keyserver.ubuntu.com) after checking their signatures with gpg; the 7 Kotlin

signatures through the mirror).

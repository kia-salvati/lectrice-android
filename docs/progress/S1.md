## Choices worth knowing

- **compileSdk 37, not 36:** Compose BOM 2026.09.00 (foundation 1.12.1) refuses to build against android-36
  (`checkAarMetadata`: "requires … version 37 or later"). android-37.0 was already installed. targetSdk stays 36.
- **Google Maven is blocked here** (404 for every artifact on maven.google.com and dl.google.com). The Google groups come
  from `https://maven.aliyun.com/repository/google` (set in the gitignored `local.properties`). Every file is pinned by
  SHA-256 in `gradle/verification-metadata.xml`, and PGP signatures are checked where they exist (S4 report).
- **`repo.maven.apache.org` is blocked here** (TLS stalls), so Maven Central is used through its other official host
  `repo1.maven.org`. Not a mirror.
